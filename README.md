# Java Lernwerkstatt ☕

Interaktive Java-Lernumgebung im Browser: Editor, simuliertes Terminal (`javac` / `java`) und ein Java-Interpreter, alles in einer einzigen HTML-Datei.

**Direkt starten:** https://c1llsh0t.github.io/Java-LernUmgebung/

## Aufbau

- **37 Lektionen** in 6 Kapiteln: Grundlagen, Kontrollstrukturen, Arrays & Methoden, Objektorientierung, Collections & mehr, Praxis
- **Schlussaufgabe nach jeder Lektion**: prüft alles, was bis dahin vorkam – ohne Tipps, ohne Lösung
- **Kapitelprüfung am Ende jedes Kapitels**: eine grosse Aufgabe, automatisch mit mehreren (auch versteckten) Tests geprüft
- **Übungen**: Lückentexte und Multiple Choice zu allen Themen
- Lösungen der Lektionen erscheinen erst nach 3 Fehlversuchen

Der Fortschritt wird im Browser (localStorage) gespeichert.
